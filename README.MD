# Faculdade

Repositório destinado à organização e ao armazenamento
de materiais desenvolvidos durante a graduação em
Sistemas de Informação.

## Organização

Cada diretório representa uma disciplina da faculdade.

Os diretórios poderão conter:
- Anotações
- Exercícios
- Trabalhos acadêmicos
- Projetos
- Materiais de estudo
